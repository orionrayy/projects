# VORENYX Branding Assets

The full title screen, logo-sized asset and Android splash replacement are included in the local project archive generated for checkpoint v1.3. The public GitHub folder stores design metadata only, not the full-size image binary in this commit.

Visual direction: moody apocalypse highway, teal/cyan shadows, rust-orange fire and a magenta anomaly vortex; survivors and abandoned vehicles foregrounded; title wordmark “DR2C VORENYX”. Intended as a new brand layer, not a change to the game's campaign.

Local full-resolution artwork: DR2C_VORENYX_title_screen.png (1672 × 941). Checksum is recorded in the local audit/SHA256SUMS.txt.

Runtime status: new logo/splash assets were staged in the overlay. Full-background integration into the in-game title-menu screen has not been runtime-verified.
