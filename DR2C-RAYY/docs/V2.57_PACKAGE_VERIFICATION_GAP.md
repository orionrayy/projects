## Root-cause interpretation

A locally generated certificate differs from the original publisher certificate and would block an in-place update over an installed package signed with the publisher key. It does not by itself explain a failed fresh installation after that package has been uninstalled. ZIP/JAR checks also do not exclude Android's rejection of the APK signature block, manifest, ABI or package metadata.

Do not make another speculative binary modification. First run official `apksigner` against this exact SHA-256, then capture the device PackageManager error with the v2.65 toolkit's `INSTALL_ATTEMPT` mode. If fresh installation succeeds but Start is inert, run `START_BUTTON` mode.
